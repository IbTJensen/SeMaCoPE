# SeMaCoPE
This package implements the **Se**mi-parametric **Ma**rkov model with **Co**nditional **P**sudo-likelihood **E**stimation (SeMaCoPE) described in the paper "Semi-parametric Markov models for multi-type point patterns" (https://arxiv.org/abs/2510.11226 currently under review).

To install the package run:
```
devtools::install_github("IbTJensen/SeMaCoPE")
```
